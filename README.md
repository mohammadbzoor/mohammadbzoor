# 👨‍💻 About Me

I'm a Full Stack Developer and AI Automation Engineer who builds complete, production-style systems — from customer-facing web apps to the backend logic and AI workflows running behind them.

My work spans full-stack platforms built with React and Firebase, RESTful APIs with Node.js and Express, and AI automation pipelines using n8n, OpenAI, and vector search tools like Pinecone and Cohere. I graduated from Al al-Bayt University's Computer Science program, where I co-built an AI-powered recruitment platform as my graduation project.

I also enjoy sharing what I learn — I've delivered a hands-on web development training course for fellow students.
